## 1. Контекст

Я (Максим, .NET-розробник) роблю тестове завдання на посаду «AI-асистент проєктів» у компанії Systematia (Львів). Їхні основні обов'язки для цієї ролі:

1. **Новини для «Захід Буг»** (zaxidbug.com) — регіональні новинні спільноти ~13 міст. Людина вручну шукає новини в місцевих джерелах, відбирає цікаве, переписує через AI за готовими промптами (окремо для соцмереж і для сайту), публікує.
2. **SEO** — раз на тиждень приходить SEO-перевірка з помилками (дубльовані Title, Description тощо), треба розібратись, виправити через AI, внести на сайт.

Компанія сама пише: «AI поки знаходить новини неякісно, тому тут потрібна людина». Тому принцип бота:

> **AI робить рутину (збір, фільтр, рерайт, перевірка), рішення приймає людина.** Нічого не публікується автоматично.

Бот — це демонстрація того, як я автоматизую їхні процеси. Він має реально працювати: ним я зроблю частину тестового (10 новин по місту Шептицький + 1 стаття), і покажу його на співбесіді з телефона.

**Дедлайн тестового — неділя 25.10.2026.** Пріоритет етапів у розділі 12. Краще менше функцій, але робочих.

## 2. Що бот робить (функціональні вимоги)

### 2.1 Новини
- Збирає новини з джерел вибраного міста (Telegram-канали, сайти громади/поліції/ДСНС/місцевих медіа).
- Лишає тільки свіжі (≤ 7 днів), прибирає дублі (одна подія з кількох джерел).
- AI оцінює кожну новину: «наскільки цікаво мешканцям цього міста» 1–5 + коротка причина.
- Показує кандидатів картками з кнопками ✅ Беру / ❌ Відкинути (з причиною) / 🔗 Джерело.
- По обраних — AI переписує:
  - **пост для соцмереж**: заголовок ≤ 100 символів, текст 100–200 слів, 2–3 короткі абзаци, посилання на джерело;
  - **статтю для сайту** (для однієї новини): заголовок 50–85 символів, текст 350–600 слів.
- Кожен текст проходить **валідатор**: ліміти + перевірка фактів (кожна цифра/дата/назва/цитата має бути в тексті джерела).
- Якщо валідатор не пройдено — автоматично 1–2 спроби переписати з фідбеком; якщо знову ні — показати ⚠️ з переліком проблем і кнопками.
- Експорт: кожен пост окремим повідомленням (зручно копіювати з телефона) + `.docx` з усім: 10 постів, стаття, 3 відкинуті новини з причинами.

### 2.2 SEO-аудит
- Надсилаю URL сайту → бот читає `robots.txt`, `sitemap.xml` (з підтримкою sitemap index), обходить сторінки (режим «швидко» 50 сторінок / «повно» до 500).
- Для кожної сторінки збирає: HTTP-статус, редирект, Title (+довжина), Description (+довжина), H1 (кількість + текст), canonical, meta robots, hreflang, картинки без alt, кількість слів.
- Знаходить проблеми (розділ 7.3), групує однотипні, рахує масштаб.
- Повертає: коротке резюме в чаті (топ-проблем з кількістю і прикладом URL) + `report.csv` файлом.

### 2.3 Щоденний дайджест
- Опційно (вмикається кнопкою): щодня о 09:00 Europe/Kyiv бот сам збирає новини і присилає «Знайдено N нових кандидатів» з кнопкою «Переглянути».

### 2.4 Доступ
- **Власник** (мій Telegram ID з конфігу) — повний доступ.
- **Усі інші** — демо-режим: ті самі меню, але дані з `demo/` (заготовлені кандидати, пости, SEO-звіт), **жодних викликів OpenAI і жодного реального краулінгу**. Зверху кожного демо-екрана: «🧪 Демо-режим».

Правила:

- `prompts/`, `config/`, `demo/` копіюються в output (`CopyToOutputDirectory`).

## 7. Модулі детально

### 7.1 Джерела новин (`Sources/`)

**TelegramChannelSource** — публічні канали через веб-прев'ю `https://t.me/s/{channel}` (без API-ключів):
- пости: `.tgme_widget_message`; текст: `.tgme_widget_message_text`; дата: `time[datetime]`; посилання: `a.tgme_widget_message_date[href]`;
- пагінація назад: `?before={messageId}` поки не вийдемо за 7 днів (макс 5 сторінок);
- пости без тексту (тільки фото/відео) — пропускати; репости — брати текст.

**RssSource** — стандартний RSS/Atom (`System.ServiceModel.Syndication` або вручну XML).

**HtmlListSource** — для сайтів без RSS: селектори в `sources.json` (`item`, `title`, `link`, `date`, `dateFormat`), потім довантаження повного тексту статті (селектор `content`).

**`config/sources.json`** — структура:
```json
{ "cities": [ { "id": "sheptytsky", "name": "Шептицький", "aliases": ["Червоноград", "Шептицька громада"],
    "localTerms": ["Шептицьк", "Червоноград", "Соснівк", "Сілець", "Гірник", "Боб'ятин", "Межиріччя"],
    "sources": [ { "name": "...", "kind": "Telegram", "url": "https://t.me/s/..." } ] } ] }
```
⚠️ **Я не даю тобі конкретні канали/сайти — знайди їх сам і перевір**:
- шукай: офіційний сайт/Telegram Шептицької міської ради, Шептицька РВА, поліція Львівщини (Telegram + сайт lv.npu.gov.ua), ДСНС Львівщини, місцеві новинні сайти/канали Шептицького (Червонограда);
- додай у `sources.json` **тільки ті, що реально віддають пости за останні 7 днів** (перевір запуском);
- у README зроби таблицю джерел: назва, тип, URL, скільки постів за 7 днів дало на момент перевірки;
- **не додавай zaxidbug.com як джерело** — це наш власний сайт, звідти брати не можна.

Помилки джерела не валять збір: логуємо, пишемо `LastError`, продовжуємо інші.

### 7.2 Обробка новин (`Core/News/`)

1. **Collect** — паралельно всі `IsEnabled` джерела міста (обмеження 4), фільтр `PublishedAt ≥ now − MaxAgeDays`.
2. **Локальність (евристика, до AI)** — якщо в тексті немає жодного `localTerms` і джерело не суто міське (прапорець `isCityOnly` у джерелі) → відкинути як «не про місто». Це економить токени.
3. **Dedup** — нормалізація (lowercase, без пунктуації/емодзі/URL), шингли по 5 слів, Jaccard ≥ 0.5 → один кластер; в кластері лишаємо найповніший текст, решту позначаємо дублями (і зберігаємо посилання на всі джерела — це потім «підтвердження з кількох джерел»).
4. **Score (AI)** — `prompts/score.md`, відповідь **строго JSON**: `{"score":1-5,"reason":"…","category":"incident|utilities|infrastructure|social|culture|sport|war|other"}`. Батчами по 10 новин в одному запиті. Невалідний JSON → 1 повтор, далі score=null.
5. Сортування кандидатів: score ↓, дата ↓. Показуємо ≥ `MinScore`, решту — в кнопці «Показати слабкі (N)».

### 7.3 Рерайт і валідація (`Core/Validation/`)

**RewriteService**: промпт (`social_post.md` або `site_article.md`) + повний `RawText` джерела (і текст інших джерел кластера, якщо є) → JSON `{"title":"…","body":"…"}`.
Цикл: генерація → валідація → якщо є **помилки** → повтор з блоком «Виправ: …список…» (макс 2 повтори) → зберегти останню версію з `ValidationJson`.

**TextValidator** (детерміновано, без AI):
| Перевірка | Пост | Стаття | Рівень |
|---|---|---|---|
| Довжина заголовка (символи, після Trim) | ≤ 100 | 50–85 | помилка |
| Слова в тексті (split по whitespace, без emoji-only токенів) | 100–200 | 350–600 | помилка |
| Абзаци (розділені порожнім рядком) | 2–3 | — | помилка |
| Посилання на джерело в тексті/окремим полем | так | так | помилка |
| Копіювання джерела: найдовший спільний фрагмент > 12 слів поспіль | — | — | помилка («переписати своїми словами») |

**FactChecker** (головна фішка, детерміновано):
- з тексту поста витягнути: числа (`\d+([.,]\d+)?`, включно з «47-річний»), дати («20 жовтня», «20.10»), суми/відсотки, цитати в «» або "", слова з великої літери не на початку речення (імена, назви);
- кожен факт шукати в тексті джерела(ел) після нормалізації;
- **українська відмінюваність**: імена/назви порівнювати за основою — перші `max(4, len−2)` символи у нижньому регістрі («Шептицькому» ~ «Шептицький»);
- числа — точний збіг; числа словами («двоє», «троє») — словник до 10 → цифра;
- результат: список `UnsupportedFacts`. Числа/дати/цитати, яких немає в джерелі → **помилка**; імена/назви → **попередження** (може бути відмінювання).

`ValidationReport` у Telegram:
```
✅ Заголовок: 87/100
✅ Текст: 156 слів, 3 абзаци
⚠️ Факти: «47 років» — немає в джерелі
```

### 7.4 Промпти (`prompts/`)

Промпти — окремі `.md` файли з плейсхолдерами `{{city}}`, `{{source_text}}`, `{{source_url}}`, `{{fix_list}}`. Обов'язково включити в `social_post.md` і `site_article.md`:

**Вимоги замовника (дослівно за змістом):**
- українською, просто, живо, конкретно; суть — у перших рядках;
- заголовок: що і де сталося; чіпко, але без обману;
- структура: що сталося → головні факти → що це означає для мешканців;
- тон під тему: проблема — спокійно й по суті; досягнення — тепло; трагедія — стримано, без сенсаційності;
- нічого не вигадувати: ні подій, ні цитат, ні цифр. Слова очевидця — ще не факт (подавати як «за словами…», не як факт);
- не копіювати текст джерела, переписати своїми словами.

**Стиль «Захід Буг» (з аналізу їхніх статей про Шептицький):**
- заголовок «Що сталося + де» через двокрапку/тире, часто з «чому/як»: «Одна ялинка на всю громаду: чому Шептицький святкуватиме Новий рік з мінімальним бюджетом»;
- лід 2–3 коротких речення = вся суть;
- далі деталі → пояснення механізму → що поки невідомо («точну суму не оприлюднили»);
- абзаци 1–3 речення, без канцеляриту;
- не повторювати лід другим абзацом.

Для статті додатково: 5–8 абзаців, підзаголовок не обов'язковий, в кінці — що відомо/що далі, без вигаданих прогнозів.

`score.md`: роль — редактор міського паблику; критерії: стосується мешканців громади напряму (комуналка, транспорт, ціни, безпека, медицина, освіта, події в місті) → високо; загальнообласні/всеукраїнські без локального зв'язку → низько; некрологи/збори/реклама — оцінювати обережно і пояснювати.

### 7.5 SEO-краулер (`Infrastructure/Seo/`)

- `HttpClient` через `IHttpClientFactory`, **`UseCookies = false`** (важливо: деякі сайти пишуть cookie «переглянуті товари» на кожну сторінку → при обході накопичується заголовок і сайт віддає 400 «Request Header Or Cookie Too Large»; ми це вже ловили на maxidveri.com).
- User-Agent: `SystematiaSeoAudit/1.0 (+contact)`; поважати `Disallow` з robots.txt для `*`.
- Sitemap: підтримка `sitemapindex`, gzip; картинки (`.jpg/.png/.webp`) відкидати.
- Вибірка: якщо в sitemap більше сторінок, ніж ліміт — **стратифікована**: рівномірно по першому сегменту шляху (`/blog`, `/shop`, `/countries`…), щоб не взяти 500 однакових товарів. У резюме писати «перевірено N з M».
- Паралельність `Concurrency`, затримка `DelayMs`, таймаут, 1 повтор при мережевій помилці.
- Окремі технічні перевірки: `/robots.txt` (є? є директива Sitemap?), неіснуюча сторінка повертає 404? (запит на `/__seo-check-404-{guid}`), http→https, www↔без www.

**SeoIssueDetector** — правила:
| Код | Умова | Важливість |
|---|---|---|
| STATUS_4XX/5XX | статус ≥ 400 для URL із sitemap | висока |
| TITLE_EMPTY / DESC_EMPTY / H1_EMPTY | порожні | висока |
| H1_MULTIPLE | > 1 H1 | середня |
| TITLE_LONG / TITLE_SHORT | > 65 / < 25 символів | середня |
| DESC_LONG / DESC_SHORT | > 160 / < 70 | низька |
| TITLE_DUP / DESC_DUP | однакові на різних URL | висока |
| CANONICAL_OTHER | canonical веде на інший URL | інфо (показати) |
| CANONICAL_REDIRECT | canonical → редирект | середня |
| NOINDEX | meta robots noindex у sitemap-URL | висока |
| HREFLANG_DUP | дублікати мов / кілька x-default | середня |
| IMG_NO_ALT | > 20% картинок без alt | низька |
| THIN_CONTENT | < 150 слів основного тексту (без script/style/nav/footer) | середня |
| TEST_PAGE | Title/H1/шлях містить lorem ipsum, test, тест | висока |
| URL_ENTITIES | у URL `quot`, `amp`, `039`, `ltb`, `|` | середня |

`report.csv`: `Url;Status;Title;TitleLen;Description;DescLen;H1Count;H1;Canonical;Robots;ImgNoAlt;Words;Issues` (роздільник `;` для Excel UA).
Резюме в чаті: топ-8 проблем: `🔴 DESC_EMPTY — 31 сторінка (напр. /blog/...)`.

### 7.6 Експорт (`Export/`)

`.docx` «Новини — {Місто} — {дата}»:
1. Заголовок, джерела, дата збору.
2. 10 постів: заголовок (Heading 2), текст, «Джерело: URL».
3. Стаття для сайту.
4. «Знайдені, але не взяті» — 3+ новини: заголовок, посилання, причина (з `RejectReason` + `RejectNote`).
Шрифт — стандартний, без кастомних стилів, щоб нормально вставлялось у Google Docs.

## 8. Telegram UX: екрани і кнопки

Загальні правила:
- `ParseMode = Html`, весь динамічний текст — через `MessageFormatter.Escape`.
- Повідомлення > 4096 символів — розбивати по абзацах.
- **callback_data ≤ 64 байти**: формат `{модуль}:{дія}:{id}[:{arg}]`, напр. `n:pk:123`, `n:rj:123:old`, `n:pg:2`, `s:mode:q`. Парсинг — в одному місці (`CallbackData`).
- Меню редагують те саме повідомлення (`EditMessageText`), а не спамлять новими.
- На кожен callback — `AnswerCallbackQuery` (інакше «годинник» на кнопці).
- Команди в меню бота (`SetMyCommands`): `/start`, `/news`, `/seo`, `/status`, `/cancel`.

### Головне меню (`/start`)
```
👋 Systematia Assistant
Місто: Шептицький · Дайджест: вимк · Кандидатів: 0

[📰 Новини]      [🔍 SEO-аудит]
[⏰ Дайджест: вимк] [ℹ️ Статус]
```

### 📰 Новини
```
📰 Новини — Шептицький
Нових: 23 · Обрано: 4/10 · Відкинуто: 2 · Готових постів: 3

[🔎 Зібрати новини]      [📋 Кандидати (23)]
[✍️ Переписати обрані (4)] [✅ Готові пости (3)]
[📰 Стаття для сайту]    [📄 Експорт .docx]
[🏙 Змінити місто]        [⬅️ Назад]
```
- **Зібрати** → «⏳ Збираю з 9 джерел…» (редагується: «4/9 джерел · 37 постів · фільтр…» → «AI оцінює 21 новину…») → «✅ Знайдено 23 кандидати (ще 8 слабких)» + [📋 Переглянути].

### Картка кандидата (по одній, пагінація)
```
3/23 · ⭐ 5/5 · 🚨 інцидент
<b>ДТП на вулиці Шевченка: двоє дітей у лікарні</b>
📅 20.10, 13:05 · Поліція Львівщини (+2 джерела)
Коротко: перші ~300 символів…
💬 AI: «прямо стосується безпеки в місті, багато очевидців»

[✅ Беру]  [❌ Відкинути]  [🔗 Джерело]
[◀️]  [3/23]  [▶️]   [⬅️ Меню]
```
- ✅ → статус Picked, лічильник «Обрано 5/10», автоперехід на наступну.
- ❌ → кнопки причини:
  `[🕐 Застаріла] [😐 Не про місто] [❓ Неперевірено] [🔁 Дубль] [✏️ Своя причина]`
  «Своя» → стан `AwaitingRejectNote`, наступне текстове повідомлення = причина.
- Якщо обрано вже 10 → попередження, але дозволити.

### ✍️ Переписати обрані
→ прогрес «Пишу пост 2/10…» → по кожному посту окреме повідомлення:
```
📝 Пост 2/10
<b>Заголовок…</b>

Текст…

🔗 Джерело: …
──────
✅ Заголовок 87/100 · ✅ 156 слів · ✅ 3 абзаци
⚠️ Факти: «47 років» немає в джерелі

[👍 Готово] [🔁 Переписати] [✏️ Свій текст] [🗑 Прибрати]
```
- «Свій текст» → стан `AwaitingPostEdit:{postId}`: я надсилаю відредагований текст (перший рядок = заголовок) → повторна валідація.

### 📰 Стаття для сайту
→ список обраних новин кнопками (з позначкою скільки джерел) → вибір → генерація статті → такий самий формат з валідацією.

### 📄 Експорт
→ `.docx` документом + кнопка «📨 Надіслати всі пости в чат по одному».

### 🔍 SEO-аудит
```
🔍 SEO-аудит
Надішли URL сайту (напр. https://maxidveri.com)
```
→ стан `AwaitingSeoUrl` → валідація URL → `[⚡ Швидко (50)] [🔬 Повно (до 500)]` → прогрес «Sitemap: 8 716 URL · перевірено 120/500 · знайдено проблем: 46» + [⛔ Скасувати] → резюме + `report.csv` + `[🔁 Ще раз] [⬅️ Меню]`.

### ⏰ Дайджест / ℹ️ Статус
- Дайджест — перемикач; при увімкненні показати час наступного запуску.
- Статус: аптайм, версія (git commit hash, вшитий при збірці), джерела (ок/помилка), витрати OpenAI сьогодні, остання помилка.

### Демо-режим (не власник)
Ті самі екрани з `demo/*.json`, кнопки працюють по демо-даних, генерація повертає заготовлені пости з затримкою 1–2 с, SEO повертає заготовлений звіт для maxidveri.com. Банер «🧪 Демо-режим» у кожному екрані.

## 9. Надійність

- Будь-яке виключення в хендлері: лог + повідомлення користувачу «Щось пішло не так, вже записав у лог» + бот продовжує працювати.
- Polling переживає мережеві помилки (retry з backoff).
- `/cancel` — скасувати поточну задачу і скинути стан очікування.
- Graceful shutdown: Ctrl+C коректно зупиняє polling і фонові задачі.
- Консоль Windows: `Console.OutputEncoding = UTF8`.

## 10. Тести (мінімум)

- `TextValidator`: межі (99/100/101 символ, 99/100/200/201 слово), абзаци.
- `FactChecker`: число є/немає, «двоє» ↔ 2, відмінювання «Шептицькому» ~ «Шептицький», цитата не з джерела.
- `TelegramChannelSource`: парсинг збереженого HTML-фікстура `t.me/s/...` (без мережі).
- `SeoIssueDetector`: кожне правило на маленьких HTML-фікстурах.
- `CallbackData`: серіалізація ≤ 64 байти, round-trip.
- `DedupService`: два перефразовані тексти однієї події → один кластер.

## 13. Правила роботи для Claude Code

- Перед кожним етапом коротко скажи план (3–5 пунктів), після — що зроблено і як перевірити.
- Коміти: Conventional Commits (`feat(seo): ...`, `fix(bot): ...`), маленькі і логічні.
- Не додавай пакети поза розділом 3 без пояснення навіщо.
- Не вигадуй API (Telegram.Bot, OpenAI SDK) — перевіряй у встановленій версії.
- Не вигадуй джерела новин, не хардкодь тестові дані у прод-код (тільки в `demo/` і `tests/`).
- Секрети ніколи не в коді, не в логах, не в комітах. Якщо випадково — одразу скажи.
- Мова коду, коментарів у коді, комітів — англійська. Мова UI бота і README — українська.
- Код на рівні, який не соромно показати на співбесіді: DI, async/await з CancellationToken, nullable enabled, без `.Result`/`.Wait()`, без God-класів.
